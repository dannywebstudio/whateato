## 검색엔진 색인 안전장치 (Phase 3.3 — 배포 전)
- `/search`: 쿼리/태그/페이지 조합을 중복 검색 결과로 Google에 노출하지 않도록 `noindex,nofollow`; canonical `/search`.
- `/restaurant/[id]`: `NEXT_PUBLIC_LAUNCH_READY=true`가 아니면 **noindex**. 출시 후에도 **verified & published 짧은 식당 설명이 충분한 경우만** 자체 소개와 canonical URL을 메타데이터로 제공.
- `/sitemap.xml`: 출시 전에는 식당 항목 없음. 출시 후에도 **한국어 검증 완료 소개 35자 이상인 영업/공개 식당만** 수록, 미검증 원장 10,000개 전체 색인 금지.
- 광고 제휴 링크·평점 구조화 데이터는 넣지 않음. 타 플랫폼 리뷰 평균을 WhatEatO 점수로 표시하지 않음.
- 실제 검색엔진 크롤링, 도메인 연결, 인덱싱은 최종 배포 후 검증. 출시 준비가 안 됐을 때 `robots.txt`는 모든 크롤러 접근 차단.
