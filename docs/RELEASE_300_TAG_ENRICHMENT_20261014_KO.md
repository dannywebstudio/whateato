## 품질 기준

1. 인허가 **업종**은 실제 매장과 다를 수 있으므로 `proposed`로만 등록. 음식·분위기와 메뉴는 출처 확인 후에만 `verified`로 승격.
2. 원본 **주소/구**는 공공 인허가 자료에서 확인된 범위만 `verified` 지역 태그로 등록. 지역과 실내 분위기는 별도로 판단.
3. 데이트·조용함·캐주얼·단체모임·한옥 등은 장소와 일치하는 개별 출처의 구체적 내용이 있을 때만 사용.
4. `verified`는 `evidence_ref` + `verified_at` 필수. `proposed`는 서비스 미노출.
5. 코드: `src/lib/restaurant-tag-order.ts`에서 음식/분위기 먼저, 지역명은 나중에 출력. 상세에서는 추가로 검증 태그 전체(최대 24개)를 같은 칩 디자인으로 표시.
6. Staging DB 검증 SQL `sql/staging_release_300_tag_acceptance_v1.sql` 결과 **PASS**: 미검증 태그 노출 상태 0, 번역 누락 0, 출처 없는 분위기 확정 0.
7. 300곳 확대 조사용 `whateato_release_cohort_tag_tasks_v1` 추가: 현재 288곳 음식/메뉴 특성부터 확인, 2곳 분위기 근거 추가 확보, 10곳 태그 편집 QA 대기.
